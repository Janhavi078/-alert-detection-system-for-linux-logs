## 🧠 ML LOGIC (IMPLEMENTATION FLOW)

### 1️⃣ PREPROCESSOR (utils/preprocessor.py)

**Responsibility**: Clean raw logs and extract structured data

**Input**: Raw log strings
```
"Failed password for root from 192.168.1.10 port 22"
```

**Output**: Dictionary
```python
{
    "raw_log": "...",
    "login_status": "failed",  # failed | success | error
    "user": "root",
    "ip_address": "192.168.1.10",
    "port": 22,
    "timestamp": None,  # If available
}
```

**Functions**:
- `clean_log(log: str) -> str` — lowercase, remove extra whitespace
- `parse_log(log: str) -> dict` — extract IP, user, status using regex
- `validate_input(logs: list) -> bool` — check logs list is valid

---

### 2️⃣ FEATURE EXTRACTOR (utils/feature_extractor.py)

**Responsibility**: Convert structured log data into numerical features for ML model

**Input**: List of parsed logs (dictionaries)

**Output**: Pandas DataFrame with columns:
```
[
  failed_login_count,      # How many failed logins in batch
  success_login_count,     # How many successful logins
  ip_frequency,            # How often this IP appears
  unique_ip_flag,          # 1 if IP is new, 0 if seen before
  failed_ratio,            # failed / (failed + success)
  error_count              # Authentication errors
]
```

**Functions**:
- `extract_features(parsed_logs: list) -> pd.DataFrame` — Main feature engineering
- `calculate_ip_frequency(ips: list) -> dict` — Track IP occurrences
- `calculate_failed_ratio(logs: list) -> float` — Failure rate

---

### 3️⃣ ISOLATION FOREST MODEL (models/isolation_forest.py)

**Responsibility**: Load/train Isolation Forest model, provide predictions

**Behavior**:
1. Try to load `data/trained_model.pkl`
2. If not found → **Train new model** on synthetic/demo data
3. contamination=0.05 (5% expected anomalies)

**Functions**:
- `__init__()` — Load or initialize model
- `train(X: pd.DataFrame) -> None` — Train on historical data
- `predict(X: pd.DataFrame) -> np.array` — Returns [-1 (anomaly), 1 (normal)]
- `get_scores(X: pd.DataFrame) -> np.array` — Get anomaly scores [0-1]
- `save_model() -> None` — Pickle model to disk

---

### 4️⃣ PREDICTOR (models/predictor.py)

**Responsibility**: Orchestrate full pipeline from raw logs to final results with explanations

**Pipeline Flow**:
1. Receive raw logs
2. Call Preprocessor → get structured data
3. Call Feature Extractor → get DataFrame
4. Call Isolation Forest → get predictions + scores
5. Generate reasons for each prediction
6. Return structured results

**Functions**:
- `predict(logs: list) -> list` — Full pipeline
- `generate_reason(parsed_log: dict, is_anomaly: bool, score: float) -> str` — Human explanation

**Reason Logic**:
```
If is_anomaly:
  - If failed_ratio > 0.7 → "Brute force attempt detected"
  - If unique_ip_flag == 1 → "Unusual IP address detected"
  - If score > 0.9 → "Critical anomaly detected"
  - Else → "Suspicious activity detected"
Else:
  - "Normal login activity"
```

## 🔌 NODE.JS INTEGRATION

### Updated mlService.js (server/services/mlService.js)

```javascript
const axios = require("axios");

const ML_SERVICE_URL = process.env.ML_SERVICE_URL || "http://localhost:8000";

const analyzeLogs = async (logs) => {
  try {
    const response = await axios.post(`${ML_SERVICE_URL}/detect`, {
      logs: logs,
    });

    if (!response.data.success) {
      throw new Error("ML service returned failure");
    }

    return response.data.results;
  } catch (error) {
    console.error("❌ ML Service Error:", error.message);
    throw new Error(`ML analysis failed: ${error.message}`);
  }
};

module.exports = { analyzeLogs };
```

### Express Route (server/routes/mlRoutes.js - NEW)

```javascript
const express = require("express");
const router = express.Router();
const { analyzeLogs } = require("../services/mlService");

router.post("/analyze", async (req, res) => {
  try {
    const { logs } = req.body;

    if (!logs || !Array.isArray(logs) || logs.length === 0) {
      return res.status(400).json({
        success: false,
        error: "Logs must be a non-empty array",
      });
    }

    const results = await analyzeLogs(logs);

    res.json({
      success: true,
      results,
    });
  } catch (error) {
    console.error("Error analyzing logs:", error);
    res.status(500).json({
      success: false,
      error: error.message,
    });
  }
});

module.exports = router;
```
